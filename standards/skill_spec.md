# 0. 速览

> 速览：技能流水线的方向卡。只定目标、原则和补丁清单，规格内容由真实需求逐步补，不预先设计。
> 最大风险：每个特例都加一条命名 / 顺序约定或转完手改，补丁越积越多，规格膨胀成另一套行为树编辑器。
> 做对的标准：补丁清单只减不增；新需求要么推进规格一步，要么登记成带标记的手改出口。
>
> 门禁：`profiles/skill_pipeline.md`、`profiles/skill_sync.md`。机制和坑见 `skill_pipeline.md`、`skill_sync.md`、`ballistic.md`、`skill_tree.md`。本卡从属于源码和运行验证，冲突时按实际走并标「疑似过时」。

# 1. 目标与不变原则

目标：合法的上游设计 → 技能规格 → trunk 配置，trunk 零手改。覆盖约八成常规技能即可，特殊技能保留手改出口，不追求百分之百自动化。

- **上下游只经规格传信息**：不再新增靠文件名、挂点顺序、特效名推断的约定；已有的列在补丁清单里逐步收掉。
- **本地写法自写全字段**：不依赖共享写法或 Bridge 旧类型的缺省值（缺省 0、60 都踩过）。
- **采样帧率一套，起止各用各的**：碰撞烘焙和形状动画帧率都是 30。动态形状的条数、动画时长帧数、伤害 Buff 的发射表条数，是同一段黄帧按 30 帧率盖住的帧数，首尾都算；检测时长是这个条数 / 30 秒。关键帧保持挂点局部偏移，不减发射点。静态或只剩一帧时，形状时长保持 1，帧率仍是 30。一次出手的主轴是该次 buff 的逻辑启动（`LaunchStartTimeMs`）。红钉和黄帧都是这条轴上的毫秒位置。单段、随机、分段、循环只决定钉落在哪，不另起时钟。客户端表现从红钉起，用持续时间或飞行时间；服务器碰撞用作者黄帧窗口，不把整段挂点挤进这次检测。父级等待不推进形状自己的时钟。两段不共用一个时长，也不拿持续时间顶没有黄帧的碰撞。
- **转出配置只读**：trunk 上的转化产物不手改；必须手改的登记进补丁清单，并写明重转会被覆盖。

- 规格载体：`SkillEditor/LocalAuthor/skill_{id}.author.json`，只由工具生成（保存时按界面状态整份重写），禁手改；本地专用不入 svn，丢失无法从已提交内容重建。
- 字段以 `SkillPipelineAuthorFile.Doc/MotionRef/FireRef` 为准；读取镜像 `SkillPipelineBridge.AuthorDoc/AuthorFire`。
- 新增或改名字段：写入与读取两侧同任务改；JsonUtility 未知字段静默丢弃、缺失字段读为 0/空。
- 代号：`Launch` 0 近战 / 1 弹道 / 2 召唤 / 3 未设。主页下拉文案是模式，只显示未设置、发射物、召唤。转树不看 Launch，按每个发射点的 `Carrier`（0 未设时，有弹道 Key 按单位，否则按形状）。`Carrier` 1 形状 / 2 单位。

# 2. 覆盖范围与补丁清单

已有：单动画；随机变体（Buff 01/03/05）；表现 / 逻辑按 HasBox 区分，作者面把带逻辑再分成形状或单位（t041）。同名形状共用形状号；每个挂点一个 Buff，客户端播特效、服务器 BTCastShape。形状采样是作者黄帧窗口，发射表只留这段。检测时长和所属 Buff 时长都是这段帧数 / 30 秒。单位的弹道 Key 在该发射点上绑定；下拉「随机弹道」确定设置后，该发从这只怪物已有 Key 里定选一把。单位主发射物不另写客户端特效。表现点的 BTCreateBuffEffect 写在 01 客户端树，不另开 Buff；同一点的额外表现预制体各写一个，跟这一发放在 01 上。特效名是资源预制体名。01 时长只等于这段动作。逻辑形状的包围盒是 `{编号}_vfxmodel_c_melee_{编号}`。发射物名正好四段 `vfxmodel_c_melee_正整数` 时编号取末段，形状号不参与；否则用作者形状号，未填才跳过。编号来自形状号时，覆盖旧号才替换占用，否则沿用已有号。编号来自发射物末段时不看覆盖旧号。发射物为空不写客户端创建特效；名字不是这四段时客户端特效用真实预制体名。单位行不改名。形状的静态开关和三轴旋转只在发射槽与轨道缓存，不进 SpellShape 模式字段，也不另加补丁。旋转写入碰撞行时取反，共享写法再取反后与滑条一致。全帧姿态相同或已是一帧时，形状时长保持 1、帧率 30，发射表仍只留窗口（未验证）。强脱离写入 `BTCreateBuffEffect.isWorldPositionStays`，弱脱离写入 `DetachBone`，都不改宿主 Buff 时长。触碰角色缺省 1 秒、触碰环境缺省 2 秒，写入受击 Buff 和客户端特效时长。形状节点间隔写 100；attackType 为 2 或 4 时触发次数上限为黄帧毫秒/100+1，其余为 1。攻击距离和元素只在技能面显示。
**已定方向（结构）**：一动画片段 = 一个动画 Buff；多段时 **00 负责切换/编排**，再创建 01/02/03…（或现状随机的 01/03/05）。逻辑形状的 Buff 加在施法者身上；事件形状的 Buff 加在发射物身上，停在当时坐标。详见 `skill_tree.md`。
**分段前中后摇等**：结构基准见 `skill_tree.md`；**转化器待实现**（顺序多段号段分配待与 `skill_sync` 可覆盖号规则对齐）。条件分支、命中后接段等仍遇真实需求再加。

补丁清单（一行一条，去向 = 收进规格字段或本地写法；收掉后删行）：

# 3. 进规格门槛与验证

- 同类需求出现三次以上才加规格字段；不到的走带标记的手改出口，登记进上面的清单。
- 新增约定或补丁必须同单登记；补丁被收掉的同单删行。
- 回归样本（几条代表性技能，转完比对 trunk 产物）：第一次改转化器时建立，之前不建。
