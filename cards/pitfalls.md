# 0. 职责定位

跨模块、可迁移的坑。每条四项：场景触发 / 规则 / 来源任务 / 最后有用（最近一次真正帮上忙的任务号）。只扫「场景触发」，命中再读规则。模块专属的坑写在对应卡的 `# 2`，这里不重复。条目上限约 20 条，超了先合并或删掉最久没用上的。

# 1. 条目

**P01 Unity 对象判空**
- 场景触发：拼名字或键时读 `UnityEngine.Object` 的 `.name`；报 NullReferenceException 却「明明判过空」。
- 规则：先用 Unity 的 `!= null` 再取属性，不用 `?.`。丢失引用的托管外壳不是 C# null。
- 来源任务：转化受击槽修复（无号）｜最后有用：t035

**P02 跨 await 持有实体（ET0035）**
- 场景触发：异步等待、倒计时、循环里用到实体 / EntityRef / TimerComponent。
- 规则：实体局部变量不跨 await；每次 await 后重新从 EntityRef 取；计时器只作为这一次 WaitAsync 的接收者，之后不再碰。
- 来源任务：t020、t023、t034｜最后有用：t034

**P03 客户端与服务端各跑一份**
- 场景触发：表现提前、闪一下、叠两次；只改客户端后服务端拒绝；不同步字段行为两端不一致。
- 规则：先确认这段逻辑在哪端执行。权威动作（加 Buff、拆单位、记账、解锁判定）只在服务端；客户端只认服务端下发的结果。不同步字段在客户端是默认值，相关逻辑限定服务端。
- 来源任务：t022、t029、t034｜最后有用：t034

**P04 时长 / 相位要用数据自己的时钟**
- 场景触发：按「进度 / 比例」查表或采样，结果偏早偏晚；两个时长看起来该相等却不等。
- 规则：除数用被查数据自身的时长（如挂点表 总帧/采样帧率），不要拿 Timeline、技能总长或别的 Buff 时长代替；也不要垫数据去迁就另一边。
- 来源任务：t006、t029｜最后有用：t029

**P05 原点与单位必须两端一致**
- 场景触发：编辑器预览对、游戏里偏；落点差一个身高；中段被拉长或拉回。
- 规则：写出数据前对齐三件事：原点（出生那一帧的真实位置，不是第 0 帧）、单位（米还是归一化）、谁再乘一次。在转换处对齐，不改运行时公式。
- 来源任务：t004、t031、t034｜最后有用：t035

**P06 缺数据就报缺，不拿相近数据顶替**
- 场景触发：某条曲线 / 资产 / 配置不存在，代码想「回退」到预制体姿态、别的文件名或跳过继续。
- 规则：静默回退会把错误数据当真写出去。缺了就不写并明确提示；只有用户认可的回退（如变体碰撞回退变体1并弹窗）才允许。
- 来源任务：t012、t027、t031｜最后有用：t031

**P07 生成或绑定的数据会覆盖手改**
- 场景触发：想手改 Gen、导表生成代码、序列化 YAML，或运行时改被数据绑定 / LayoutGroup 管着的字段。
- 规则：从源头改（编辑器里绑定后点生成、改导表、在编辑器里接节点），不手改产物。
- 来源任务：t009、t020、t022、t034｜最后有用：t034

**P08 共用资源别为一个需求改全局**
- 场景触发：要改的配置 / Override / AI 超时 / globalconfig 被多个怪或技能共用。
- 规则：优先加只影响本例的开关或单独资源；整份覆盖与改共用参数要先问。
- 来源任务：t030、t032、t035｜最后有用：t035

**P09 边界帧单独处理**
- 场景触发：「到 1 / 到期」那一帧行为不对；正常帧都对。
- 规则：结束分支与到期常在同一帧，先处理再销毁；「读不到」不等于「已完成」；标记位在真正成功后再置。
- 来源任务：t032｜最后有用：t032

**P10 先排除放大器，再找根因**
- 场景触发：多个症状同时出现（碰撞、拉扯、数量差异），容易先改最显眼的。
- 规则：一次关掉一个可疑因素看症状是否消失；下游症状（碰撞放大、数量差）不当根因。
- 来源任务：t003、t004、t011｜最后有用：t029

**P11 类型判断看权威字段**
- 场景触发：用某个「通常相关」的值推断类型（如 Key>0 当弹道、文件名当类型）。
- 规则：读真正定义类型的字段（如 LaunchType）；代理信号在需求变化后会失真。
- 来源任务：t033｜最后有用：t033

**P12 编辑器里打开着的资源不就地删**
- 场景触发：重建 / 替换一个可能正在窗口里打开的资源（Timeline、Inspector 选中对象）。
- 规则：先让窗口放开并取消选中，再删文件重建；不在窗口握着时 Destroy 子对象。
- 来源任务：t033｜最后有用：t033

**P13 SVN 范围最小、冲突即停**
- 场景触发：任何 update / commit / 外链目录 / 「提交时没有改动」。
- 规则：只对用到的路径 scoped update；冲突停下不回退；外链是独立工作副本，要在该层提交或查 status。
- 来源任务：t014、t016、t035｜最后有用：t035
