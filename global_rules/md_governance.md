# 0. 职责定位

本文件是 ET81-workspace Markdown 的唯一全局规则。约束版头、命名、章节预算、最小读取、版本、索引和防爆炸。

键值项的最小集与上限见 [`kv_budget.md`](./kv_budget.md)。本文件不保存任务状态。适用于全部受管理 `.md`；`.cursor/rules/*.mdc` 不套用四行版头。

# 1. 两层结构与文类

不要把下面两层都叫「字段」：

| 层 | 形态 | 谁用 | 权威 |
|---|---|---|---|
| 章节布局 | `# 0` … `# N. 版本历史` | 每一个受管理 md | 本文 §2 |
| 键值项 | `- name：value` 行（见 kv_budget） | 仅游标、模块配置、开工契约 | `kv_budget.md` |

`# 1` 只服务本文件，禁止跨文件按序号对齐。知识文档只有章节，没有键值预算。

创建前选唯一文类；跨文类只链接，不复制同一事实。

| 文类 | 路径 | 写什么 |
|---|---|---|
| 硬约束 | `AGENTS.md` | 短规则 |
| 导航 | `project_index.md`、`project_pipeline.md`、`*/_index.md` | 路径、读取时机、用户管线 |
| 文档法 | 本文件 | 如何写 md |
| 键值预算 | `kv_budget.md` | 三种状态文件的键 |
| 游标 / 配置 / 契约 | `project_cursor.md`、`profiles/`、`contracts/current.md` | 现在 / 模块边界 / 这一单 |
| JSON 数据 | `contracts/current_scope.json`、`targets/`、`standards/<editor>/` | 阶段、路径、证据、编辑目标、按编辑器知识 |
| 标准 / 审计 | `standards/` | 长期知识；授权痕迹 |

# 2. 章节、篇幅与最小读取

一级标题是该文件自己的目录，采用与键值项相同的原则：**最小必要、能省则省、硬上限、不重复、不写无意义解释**。

| 规则 | 要求 |
|---|---|
| 最小 | 正好包含 `# 0. 职责定位` 与最后一个 `# N. 版本历史`（至少 2 个一级标题） |
| 上限 | 一级标题总数 **≤ 8**（含 #0 与版本历史，即中间最多 6 节） |
| 中间节 | 一节一事；不为和其他文件对齐而空号 |
| 禁止重复 | 同一事实只出现在一个一级标题下；`# 0` 已写的职责/非职责不要再开「说明」「概述」「注意」节 |
| 禁止空话 | 不写复述版头的导读节、不写「综上所述」、不为铺垫单独开节。导读最多放在 `# 0` 里三句 |
| 二级标题 | 不计入上限，但禁止用一堆 H2 规避 H1 上限去另造目录 |

索引类中间节通常只需「文件索引」；游标/契约/配置的中间节只按键值分组，不写背景教程。

**篇幅按读取等级分级**（等级是打开频率与注意力成本，不是权威高低）。L0 每轮注入或冷启动必读，必须短；L2 按需打开，才允许给人看的解释。禁止把文件改成更低读取等级来换行数。全局一刀切 500 行不适用。

| 读取等级 | 软上限 | 硬上限 | 读者 |
|---|---|---|---|
| L0 | 80 | 120 | Agent；每轮/冷启动 |
| L1 | 180 | 250 | Agent；进入该类任务时 |
| L2 | 350 | 500 | 人 + 按需 Agent |

软上限：机检警告。硬上限：机检失败。行数按物理行（含空行）。

**违规处置（必须按序，禁止跳到抬上限或重写全文）：**

| 违规 | 只允许这样做 |
|---|---|
| 一级标题 > 8 | ① 删除空话/重复节 → ② 合并同责节 → ③ 溢出内容改为链接到已有唯一事实源 → ④ 仍放不下才按 §3 创建五问拆新文件。禁止抬高 8、禁止 `v2` 副本、禁止用 H2 另造目录 |
| 超过该等级行数硬上限 | 同上序；需要展开的理解性文字拆到 **L2** 文件并链接，不把本文件降级。禁止抬行数上限、禁止把 L0 改成 L2 来规避 |
| 超过软上限未过硬上限 | 先删空话与重复；能链则链。不要求立刻拆文件 |
| 缺少 `#0` 或版本历史 | 只补缺的那一节，不顺手增加中间节 |
| 两节写同一事实 | 留下唯一职责那一节，另一节删除或改为一句链接 |
| 空话/复述版头的节 | 整节删除；最多把一句并入 `#0` |
| 机检 `MD_H1_MAX` / `MD_LINE_MAX` | 按上表处理本文件后重跑 `runtime/etctl.ps1 check`，通过才算完成 |

打开任一 md：先版头 → 只扫一级标题 → 再读相关节。禁止默认整篇通读。跨文件先读索引，再对目标文件做这三步。

# 3. 版头、命名与创建

四行版头：

```markdown
> 最新修改时间：YYYY-MM-DD HH:mm UTC+8
> 版本号：1.0.0
> 文档状态：草案
> 读取等级：L1（读取时机）
```

- 时间 `UTC+8` 到分钟；新文件 `1.0.0`。
- 状态：`草案`、`生效`、`活动`、`已替代`。游标与 `contracts/current.md` 固定 `活动`。
- 读取等级 L0 / L1 / L2，并写触发条件。先按打开频率定级，再受该级行数约束；不得为多写而降级。

命名：除 `AGENTS.md` 外小写英文+下划线；索引 `_index.md`；模板 `_template.md`；模块 `profiles/<module_id>.md`；活契约只有 `contracts/current.md`。JSON 数据用 snake_case 文件名与字段，不套四行版头，须在最近 `_index.md` 登记。禁止 `final`/`new`/`v2`/日期归档契约。

创建五问：唯一职责、读者与读取时机、不能并入的理由、文类、索引位置。不明则不建。同批完成版头、章节、历史和索引登记。

# 4. 版本、索引与防爆炸

| 变更类型 | 时间 | 版本 | 历史条目 |
|---|---|---|---|
| 拼写、链接、格式 | 更新 | 不升 | 不写 |
| 游标/契约键值**取值**变化 | 更新 | 不升 | 不写 |
| 审计表追加一行 | 更新 | 不升 | 不写 |
| 修正歧义 | 更新 | PATCH | 写 1 条 |
| 新增兼容键或节 | 更新 | MINOR | 写 1 条 |
| 职责破坏性变化 | 更新 | MAJOR | 写 1 条 |

版本历史最多 5 条。禁止日报、逐任务 md、并行快照。行数上限见 §2，不使用全局 400/500。

每个受管理子目录要有 `_index.md`（只登记直接子级）。`project_index.md` 只登记根控制文件和一级目录。
